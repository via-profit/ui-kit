## Структура репозитория

Монорепозиторий с двумя пакетами (npm workspaces):

- `packages/ui-kit` — библиотека `@via-profit/ui-kit`, которая публикуется в npm. Документация компонентов лежит в `packages/ui-kit/docs`;
- `packages/ui-kit-website` — сайт документации. Он показывает файлы из `packages/ui-kit/docs` и живые примеры из `src/examples`.

## Разработка

Команды запускаются из корня репозитория:

```bash
npm install        # зависимости обоих пакетов
npm start          # сайт документации в режиме разработки
npm run build      # сборка библиотеки в packages/ui-kit/dist
npm run i18n       # извлечь и скомпилировать переводы сайта
```

После изменения текстов в примерах сайта запускайте `npm run i18n`, иначе вместо текста на сайте будут идентификаторы сообщений.

## Список изменений

Все заметные изменения записываются в `packages/ui-kit/CHANGELOG.md` в раздел «Не выпущено» сразу, вместе с самим изменением. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/): «Добавлено», «Изменено», «Устарело», «Удалено», «Исправлено».

Изменения, которые требуют правок в коде пользователей, отмечайте в разделе «Изменено» и описывайте, что именно нужно поменять.

## Публикация в npm

Версии следуют [семантическому версионированию](https://semver.org/lang/ru/). Пока мажорная версия равна 0, несовместимые изменения выпускаются как минорная версия (`0.3.0` → `0.4.0`), а исправления — как патч (`0.3.0` → `0.3.1`).

Для публикации нужен доступ к организации `@via-profit` в npm (`npm login`).

1. **Поднимите версию** в `packages/ui-kit/package.json`, например `0.3.0` → `0.4.0`.

2. **Оформите список изменений.** В `packages/ui-kit/CHANGELOG.md` замените заголовок «Не выпущено» на номер версии и дату, а над ним добавьте новый пустой раздел «Не выпущено»:

   ```md
   ## Не выпущено

   ## 0.4.0 — 2026-10-01
   ```

3. **Соберите пакет с нуля.** Сборка не очищает `dist`, а файлы удалённых компонентов из прошлых сборок попали бы в пакет:

   ```bash
   rm -rf packages/ui-kit/dist
   npm run build
   ```

   Сборка компилирует TypeScript в `packages/ui-kit/dist` и копирует туда `README.md`, `CHANGELOG.md`, `LICENSE` и `package.json`. Публикуется именно папка `dist`, поэтому компоненты импортируются как `@via-profit/ui-kit/Button`, без `dist` в пути.

4. **Проверьте содержимое пакета** — список файлов и версию:

   ```bash
   cd packages/ui-kit/dist
   npm pack --dry-run
   ```

5. **Опубликуйте** из папки `dist`:

   ```bash
   npm publish
   cd ../../..
   ```

6. **Зафиксируйте выпуск** коммитом и тегом:

   ```bash
   git add packages/ui-kit/package.json packages/ui-kit/CHANGELOG.md
   git commit -m "chore(release): 0.4.0"
   git tag v0.4.0
   git push && git push --tags
   ```
