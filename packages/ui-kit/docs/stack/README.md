## Описание

Компонент `<Stack>` выстраивает элементы в столбец или в строку с одинаковым отступом между ними. Это самая частая раскладка: поля формы, разделы карточки, кнопки в панели.

Дети остаются обычными элементами — оборачивать каждый не нужно. Отступ задаётся свойством `gap`: шаг [шкалы отступов](#шкала-отступов) темы или любая длина CSS.

Стек раскладывает элементы по одной оси. Для раскладки в колонки используйте [сетку](../grid/README.md), подробнее — в разделе [Стек или сетка](#стек-или-сетка).

_Пример использования:_

```tsx
import React from 'react';
import Stack from '@via-profit/ui-kit/Stack';
import TextField from '@via-profit/ui-kit/TextField';
import Checkbox from '@via-profit/ui-kit/Checkbox';
import Button from '@via-profit/ui-kit/Button';

const Example: React.FC = () => (
  <Stack gap="md">
    <TextField fullWidth label="Email" />
    <TextField fullWidth type="password" label="Пароль" />
    <Checkbox>Запомнить меня</Checkbox>
    <Button color="primary">Войти</Button>
  </Stack>
);

export default Example;
```

В столбце элементы растягиваются на всю ширину (`align="stretch"`). Чтобы они занимали ширину содержимого, передайте `align="flex-start"`.

## Строка

С `direction="row"` элементы идут в строку и по умолчанию выровнены по центру по вертикали. Стеки можно вкладывать друг в друга.

- `justify` — распределение по строке, например `space-between`: заголовок слева, кнопки справа;
- `wrap` — элементы переносятся на следующую строку, если не помещаются;
- `inline` — стек занимает ширину содержимого, а не всю ширину родителя.

```tsx
<Stack gap="lg">
  <Stack direction="row" justify="space-between" wrap>
    <strong>Документы</strong>
    <Stack direction="row" gap="sm">
      <Button>Импорт</Button>
      <Button color="primary">Создать</Button>
    </Stack>
  </Stack>

  <Stack direction="row" gap="sm" wrap>
    {tags.map(tag => (
      <Badge key={tag}>{tag}</Badge>
    ))}
  </Stack>
</Stack>
```

## Стек или сетка

Разница между стеком и сеткой — в количестве осей, а не в направлении:

- **одна ось — стек.** Элементы идут друг за другом столбцом или строкой, каждый своей ширины или высоты: поля формы, кнопки в подвале, теги;
- **две оси — сетка.** Ячейки выравниваются и по колонкам, и по строкам: поля формы в несколько колонок, карточки, раскладка «основная колонка + боковая».

Например, кнопки «Отменить» и «Сохранить» в подвале — одна ось, ширина по содержимому:

```tsx
<Stack direction="row" gap="sm">
  <Button>Отменить</Button>
  <Button color="primary">Сохранить</Button>
</Stack>
```

Если же кнопки должны быть одинаковой ширины и делить строку поровну, это уже колонки — сетка:

```tsx
<Grid columns={2} gap="sm">
  <Button>Отменить</Button>
  <Button color="primary">Сохранить</Button>
</Grid>
```

## Шкала отступов

Отступы берутся из темы: `xs`, `sm`, `md`, `lg`, `xl`. По умолчанию это `0.25em`, `0.5em`, `1em`, `1.5em` и `2em`. Отступы в `em`, поэтому они растут вместе с размером шрифта. Шкалу можно изменить в [теме](../theming/README.md#шкала-отступов).

Пользуйтесь шкалой, а не произвольными значениями: тогда отступы во всём приложении будут согласованы. Произвольное значение (`gap="0.75em"`) или число пикселей (`gap={12}`) тоже работает — для редких случаев.

```tsx
<Stack direction="row" gap="xs">…</Stack>
<Stack direction="row" gap="xl">…</Stack>
```

## Свойства

Помимо перечисленных ниже, `<Stack>` принимает атрибуты элемента `<div>`. `ref` указывает на этот же элемент.

### `direction`
Направление: `column` — друг под другом, `row` — в строку.
- Тип: `'column' | 'row'`
- По умолчанию: `'column'`
- Обязательное: нет

### `gap`
Отступ между элементами: шаг шкалы темы, длина CSS или число пикселей.
- Тип: `'xs' | 'sm' | 'md' | 'lg' | 'xl' | string | number`
- По умолчанию: `'md'`
- Обязательное: нет

### `align`
Выравнивание поперёк направления (`align-items`).
- Тип: `string`
- По умолчанию: `'stretch'` для столбца, `'center'` для строки
- Обязательное: нет

### `justify`
Распределение вдоль направления (`justify-content`).
- Тип: `string`
- По умолчанию: `'flex-start'`
- Обязательное: нет

### `wrap`
Если `true`, элементы строки переносятся на следующую строку.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

### `inline`
Если `true`, стек занимает ширину содержимого.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

### `as`
Элемент стека: `ul`, `ol`, `nav`, `section` и другие — например, `<Stack as="ul">` для списка ссылок. У списков (`ul`, `ol`, `dl`) убираются отступы и маркеры браузера.
- Тип: `React.ElementType`
- По умолчанию: `'div'`
- Обязательное: нет
