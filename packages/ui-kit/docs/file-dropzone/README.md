## Описание

Загрузка файла — область с пунктирной рамкой: файл выбирают нажатием или перетаскивают на неё. Пока файл перетаскивается над областью, она подсвечивается.

Выбранный файл показывается строкой: иконка, имя в одну строку (длинное — с многоточием, целиком — во всплывающей подсказке), размер, кнопка «Заменить» и кнопка удаления. Новый файл можно перетащить и на эту строку — он заменит прежний.

Компонент контролируемый: файл хранится у вас, передайте его в `value`, а новый принимайте в `onChange`. При удалении приходит `null`.

_Пример использования:_

```tsx
import React from 'react';
import FileDropzone from '@via-profit/ui-kit/FileDropzone';

const Example: React.FC = () => {
  const [file, setFile] = React.useState<File | null>(null);

  return (
    <FileDropzone
      value={file}
      onChange={setFile}
      label="Прикрепить чек"
      hint="JPG, PNG, PDF до 10 МБ"
      replaceLabel="Заменить"
      removeLabel="Удалить файл"
    />
  );
};

export default Example;
```

## Типы и размер файла

- `accept` — какие файлы принимаются, как у `<input type="file">`: MIME-тип (`image/png`), группа (`image/*`) или расширение (`.pdf`) через запятую. Окно выбора файла показывает только подходящие, а перетащенный файл проверяется тем же правилом;
- `maxSize` — наибольший размер в байтах.

Неподходящий файл не попадает в `onChange`. Вместо этого вызывается `onReject(file, reason)`: `reason` — `'type'` или `'size'`. Скажите пользователю, что не так, например уведомлением.

```tsx
<FileDropzone
  value={file}
  onChange={setFile}
  accept="image/jpeg,image/png,application/pdf"
  maxSize={10 * 1000 * 1000}
  onReject={(rejected, reason) =>
    toast(reason === 'size' ? 'Файл больше 10 МБ' : 'Можно JPG, PNG или PDF', { type: 'error' })
  }
/>
```

## Подписи

Подписи по умолчанию на английском — передавайте их на языке вашего интерфейса:

- `label` — строка пустой области (`Choose a file`);
- `hint` — вторая строка: какие файлы и какого размера;
- `replaceLabel` — кнопка замены (`Replace`);
- `removeLabel` — название кнопки удаления для программ чтения с экрана и её подсказка (`Remove the file`).

Размер выбранного файла выводит `formatSize`. По умолчанию это функция `formatFileSize` — «54.1 KB», «2.3 MB». Её можно импортировать отдельно или передать свою, например с русскими единицами.

## В форме

Область растягивается на ширину родителя и имеет минимальную высоту, поэтому хорошо стоит рядом с многострочным полем: например, комментарий слева, файл справа. С `react-hook-form` подключите её через `Controller`:

```tsx
<Controller
  control={control}
  name="receipt"
  render={({ field }) => (
    <FileDropzone value={field.value} onChange={field.onChange} label="Прикрепить чек" />
  )}
/>
```

`disabled` выключает выбор, перетаскивание и кнопки.

## Клавиатура и доступность

- пустая область — кнопка: на неё переходят Tab и выбирают файл Enter или пробелом;
- в строке выбранного файла «Заменить» и удаление — обычные кнопки;
- у кнопки удаления нет текста, её название для программ чтения с экрана — `removeLabel`.

## Переопределение

`<FileDropzone>` состоит из компонента:

- `<Area>` — область с рамкой; получает `active` (файл над областью), `filled` (файл выбран) и `disabled`

Используйте свойство `overrides`, чтобы переопределить его. Проще всего расширить стандартный компонент с помощью `styled`. Создавайте переопределения один раз — вне компонента, а не при рендере.

```tsx
import styled from '@emotion/styled';
import FileDropzone from '@via-profit/ui-kit/FileDropzone';
import FileDropzoneArea from '@via-profit/ui-kit/FileDropzone/FileDropzoneArea';

const Area = styled(FileDropzoneArea)`
  min-height: 10em;
`;

// Created once, outside of the component
const overrides = { Area };
```

## Свойства

Помимо перечисленных ниже, `<FileDropzone>` принимает атрибуты элемента `<div>`. `ref` указывает на этот же элемент.

#### `value`
Выбранный файл, `null` — файла нет.
- Тип: `File | null`
- Обязательное: **да**

#### `onChange`
Вызывается с выбранным файлом или с `null` при удалении.
- Тип: `(file: File | null) => void`
- Обязательное: **да**

#### `accept`
Какие файлы принимаются, как `accept` у `<input type="file">`.
- Тип: `string`
- По умолчанию: `undefined` — любые
- Обязательное: нет

#### `maxSize`
Наибольший размер файла в байтах.
- Тип: `number`
- По умолчанию: `undefined` — без ограничения
- Обязательное: нет

#### `onReject`
Файл не принят: не подходит тип или он больше `maxSize`.
- Тип: `(file: File, reason: 'type' | 'size') => void`
- По умолчанию: `undefined`
- Обязательное: нет

#### `label`
Строка пустой области.
- Тип: `React.ReactNode`
- По умолчанию: `'Choose a file'`
- Обязательное: нет

#### `hint`
Вторая строка пустой области.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `replaceLabel`
Кнопка замены файла.
- Тип: `React.ReactNode`
- По умолчанию: `'Replace'`
- Обязательное: нет

#### `removeLabel`
Название кнопки удаления.
- Тип: `string`
- По умолчанию: `'Remove the file'`
- Обязательное: нет

#### `formatSize`
Размер выбранного файла.
- Тип: `(bytes: number) => React.ReactNode`
- По умолчанию: `formatFileSize`
- Обязательное: нет

#### `disabled`
Если `true`, файл нельзя выбрать, перетащить, заменить или удалить.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

#### `overrides`
Объект для переопределения составных компонентов. Подробнее в разделе [Переопределение](#переопределение).
- Тип: `FileDropzoneOverrides`
- По умолчанию: `undefined`
- Обязательное: нет
