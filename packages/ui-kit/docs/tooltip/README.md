## Описание

Подсказка — короткий текст, который появляется при наведении на элемент или при переходе к нему с клавиатуры. Чаще всего она подписывает кнопки-иконки.

Оберните элемент в `<Tooltip>` и передайте текст в `title`. Элемент должен быть один и должен принимать `ref`, обработчики указателя и фокуса: это DOM-элемент или компонент, который передаёт их в DOM-элемент, например [кнопка](../button/README.md). Если `title` пустой, подсказка не показывается.

Подсказка появляется через 400 мс после наведения (`enterDelay`) и скрывается через 100 мс после ухода указателя (`leaveDelay`). За это время указатель можно перевести на саму подсказку, например чтобы выделить текст. Клик по элементу скрывает подсказку.

На сенсорных экранах наведения нет, поэтому подсказка там не показывается. Не прячьте в ней то, без чего нельзя обойтись.

_Пример использования:_

```tsx
import React from 'react';
import Button from '@via-profit/ui-kit/Button';
import Tooltip from '@via-profit/ui-kit/Tooltip';

const Example: React.FC = () => (
  <Tooltip title="Копировать">
    <Button iconOnly variant="outlined">
      <CopyIcon />
    </Button>
  </Tooltip>
);

export default Example;
```

## Расположение и стрелка

- `placement` — желаемое место подсказки: `top`, `bottom`, `left`, `right` и варианты с выравниванием `top-start`, `bottom-end` и другие, как у [Popper](../popper/README.md). По умолчанию `top`. Если места не хватает, подсказка переходит на другую сторону;
- `arrow` — стрелка, указывающая на элемент;
- `offset` — расстояние до элемента в пикселях, по умолчанию 8.

Длинный текст переносится, ширина подсказки не больше `20em`.

```tsx
<Tooltip arrow placement="top-start" title="Подсказка">
  <Button variant="outlined">top-start</Button>
</Tooltip>
```

## Подсказка как описание

По умолчанию подсказка служит названием элемента: строковый `title` становится его `aria-label`. Так кнопка-иконка получает имя для программ чтения с экрана. Если у элемента уже есть `aria-label`, он не заменяется.

Если у элемента есть свой текст, а подсказка его дополняет, передайте `describeChild`. Тогда элемент получит `aria-describedby`, и программа чтения с экрана прочитает подсказку после названия. С `describeChild` в `title` можно передать не только строку.

Отключённая кнопка не получает событий указателя и фокуса, поэтому подсказку нужно повесить на обёртку с `tabIndex={0}`.

```tsx
<Tooltip describeChild title="Клиент и его сделки будут удалены без возможности восстановления">
  <Button variant="outlined">Удалить клиента</Button>
</Tooltip>

<Tooltip describeChild title="Сначала заполните реквизиты">
  <span tabIndex={0}>
    <Button disabled>Выставить счёт</Button>
  </span>
</Tooltip>
```

## Клавиатура и доступность

- подсказка появляется сразу, когда элемент получает фокус с клавиатуры, и скрывается, когда фокус уходит. После клика мышью фокус подсказку не показывает;
- Escape скрывает подсказку, где бы ни был фокус;
- элемент подсказки получает роль `tooltip` и `id`, на который ссылается `aria-describedby` элемента в режиме `describeChild`;
- подсказка показывается поверх модальных окон: её `z-index` на единицу больше `theme.zIndex.modal`.

Чтобы управлять видимостью самостоятельно, передайте `isOpen` и `onOpenChange`. `onOpenChange(isOpen)` вызывается, когда подсказка хочет появиться или скрыться.

## Переопределение

`<Tooltip>` состоит из компонентов:

- `<Container>` — блок с текстом подсказки
- `<Arrow>` — стрелка; выводится только с `arrow` и получает фактическое расположение подсказки в `placement`

Используйте свойство `overrides`, чтобы переопределить один или несколько компонентов. Проще всего расширить стандартный компонент с помощью `styled`. Создавайте переопределения один раз — вне компонента, а не при рендере. Стрелка берёт цвет фона у `<Container>`, поэтому меняется вместе с ним.

_Пример использования:_ светлая подсказка с тенью для пояснения термина в тексте.

```tsx
import styled from '@emotion/styled';
import Tooltip from '@via-profit/ui-kit/Tooltip';
import TooltipContainer from '@via-profit/ui-kit/Tooltip/TooltipContainer';

const Container = styled(TooltipContainer)`
  padding: 0.75em 1em;
  background-color: ${({ theme }) => theme.color.surface.toString()};
  color: ${({ theme }) => theme.color.textPrimary.toString()};
  box-shadow: 0 0.3em 1.2em rgba(0, 0, 0, 0.18);
`;

// Created once, outside of the component
const overrides = { Container };

<p>
  Сумма указана с учётом{' '}
  <Tooltip describeChild arrow overrides={overrides} title="Налог на добавленную стоимость, 20%">
    <Term tabIndex={0}>НДС</Term>
  </Tooltip>
  .
</p>;
```

## Свойства

#### `title`
Текст подсказки. Если пустой, подсказка не показывается.
- Тип: `React.ReactNode`
- Обязательное: **да**

#### `children`
Элемент, к которому привязана подсказка. Один элемент, принимающий `ref`.
- Тип: `React.ReactElement`
- Обязательное: **да**

#### `placement`
Желаемое расположение подсказки.
- Тип: `AnchorPos`
- По умолчанию: `'top'`
- Обязательное: нет

#### `arrow`
Если `true`, показывается стрелка.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

#### `enterDelay`
Задержка появления после наведения, в мс. При фокусе с клавиатуры подсказка появляется сразу.
- Тип: `number`
- По умолчанию: `400`
- Обязательное: нет

#### `leaveDelay`
Задержка скрытия после ухода указателя, в мс.
- Тип: `number`
- По умолчанию: `100`
- Обязательное: нет

#### `describeChild`
`false` — подсказка называет элемент (`aria-label`), `true` — описывает его (`aria-describedby`).
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

#### `isOpen`
Видимость контролируемой подсказки. Передавайте вместе с `onOpenChange`.
- Тип: `boolean`
- По умолчанию: `undefined`
- Обязательное: нет

#### `onOpenChange`
Вызывается, когда подсказка хочет появиться или скрыться.
- Тип: `(isOpen: boolean) => void`
- По умолчанию: `undefined`
- Обязательное: нет

#### `offset`
Расстояние от элемента, в пикселях.
- Тип: `number`
- По умолчанию: `8`
- Обязательное: нет

#### `zIndex`
`z-index` подсказки.
- Тип: `number`
- По умолчанию: `theme.zIndex.modal + 1`
- Обязательное: нет

#### `id`
`id` элемента подсказки.
- Тип: `string`
- По умолчанию: создаётся автоматически
- Обязательное: нет

#### `overrides`
Объект для переопределения составных компонентов. Подробнее в разделе [Переопределение](#переопределение).
- Тип: `TooltipOverrides`
- По умолчанию: `undefined`
- Обязательное: нет
