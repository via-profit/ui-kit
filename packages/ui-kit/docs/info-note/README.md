## Описание

Информер — короткий текст в форме или карточке, который пользователь должен увидеть прямо здесь, без нажатий: правило, без которого легко ошибиться. Например, в форме сверки: «В сверку попадают только выполненные заявки».

Информер всегда на виду, поэтому пишите в нём одну-две фразы. Если пояснение длинное или нужно не всем — уберите его в [подсказку по нажатию](../hint-popover/README.md).

_Пример использования:_

```tsx
import React from 'react';
import InfoNote from '@via-profit/ui-kit/InfoNote';

const Example: React.FC = () => (
  <InfoNote>
    В сверку попадают только <strong>выполненные</strong> заявки клиента за выбранный период.
  </InfoNote>
);

export default Example;
```

## Варианты

Свойство `variant` задаёт смысл информера, а с ним — цвет полосы слева, фона и иконки. Цвета берутся из [темы](../theming/README.md): `accentPrimary`, `success`, `warning` и `error`.

- `info` — то, что важно знать (по умолчанию);
- `success` — что-то готово или прошло проверку;
- `warning` — здесь легко ошибиться: действие необратимо, данные пересекаются, что-то не учтётся;
- `error` — что-то пошло не так и мешает продолжить.

```tsx
<Stack gap="sm">
  <InfoNote>Изменения вступят в силу со следующего месяца.</InfoNote>
  <InfoNote variant="success">Реквизиты проверены: организация действует.</InfoNote>
  <InfoNote variant="warning">Лист закрыт: новые начисления невозможны.</InfoNote>
  <InfoNote variant="error">Договор истёк: заявку по нему выполнить нельзя.</InfoNote>
</Stack>
```

<ExampleInfoNoteVariants />

Не делайте предупреждением всё подряд: если жёлтых информеров на экране много, их перестают читать.

## Заголовок и иконка

- `title` — короткая первая строка жирным, когда у информера есть тема: «Пересечение», «Лист закрыт»;
- `icon` — своя иконка вместо иконки варианта. `icon={false}` убирает иконку — например, когда информеров несколько подряд.

```tsx
<InfoNote variant="warning" title="Пересечение">
  В это время техника уже занята в заявке №128. Сохранить заявку можно, проверьте расписание.
</InfoNote>

<InfoNote icon={false}>Без иконки.</InfoNote>
```

## Информер или подсказка по нажатию

| | Информер | [Подсказка по нажатию](../hint-popover/README.md) |
|---|---|---|
| Виден | всегда | после нажатия на «?» |
| Объём | одна-две фразы | можно абзац или список |
| Когда | это должен знать каждый, кто заполняет форму | пояснение нужно не всем и не всегда: что делает кнопка, откуда берётся число |

Подсказки ставят там, где без них действительно ошибаются, а не у каждого поля.

## Доступность

- у информера роль `note`: программы чтения с экрана объявляют его как примечание;
- иконка скрыта от программ чтения с экрана (`aria-hidden`), смысл передаёт текст. Не полагайтесь только на цвет: для предупреждения пишите, в чём оно состоит;
- информер не объявляется сам при появлении. Если он появляется в ответ на действие и о нём нужно сообщить сразу, передайте `role="alert"` или `role="status"`.

## Переопределение

`<InfoNote>` состоит из компонентов:

- `<Container>` — блок с полосой слева и фоном; получает `variant`
- `<Icon>` — иконка варианта; получает `variant`, своя иконка из `icon` приходит в `children`
- `<Content>` — заголовок и текст справа от иконки
- `<Title>` — заголовок; выводится только с `title`

Используйте свойство `overrides`, чтобы переопределить один или несколько компонентов. Проще всего расширить стандартный компонент с помощью `styled`. Создавайте переопределения один раз — вне компонента, а не при рендере.

_Пример использования:_ информер без полосы, со скруглением со всех сторон.

```tsx
import styled from '@emotion/styled';
import InfoNote from '@via-profit/ui-kit/InfoNote';
import InfoNoteContainer from '@via-profit/ui-kit/InfoNote/InfoNoteContainer';

const Container = styled(InfoNoteContainer)`
  border-left: none;
  padding: 0.8em 1em;
`;

// Created once, outside of the component
const overrides = { Container };

<InfoNote overrides={overrides}>Оплата поступит в течение дня.</InfoNote>;
```

## Свойства

Помимо перечисленных ниже, `<InfoNote>` принимает атрибуты элемента `<div>`. `ref` указывает на этот же элемент.

#### `variant`
Смысл информера и его цвет.
- Тип: `'info' | 'success' | 'warning' | 'error'`
- По умолчанию: `'info'`
- Обязательное: нет

#### `title`
Короткая первая строка жирным.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `icon`
Своя иконка вместо иконки варианта. `false` — без иконки.
- Тип: `React.ReactNode`
- По умолчанию: иконка варианта
- Обязательное: нет

#### `children`
Текст информера.
- Тип: `React.ReactNode`
- Обязательное: нет

#### `overrides`
Объект для переопределения составных компонентов. Подробнее в разделе [Переопределение](#переопределение).
- Тип: `InfoNoteOverrides`
- По умолчанию: `undefined`
- Обязательное: нет
