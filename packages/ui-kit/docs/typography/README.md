## Описание

Компоненты типографики — это элементы HTML с оформлением ui-kit: заголовки, абзацы, выделение текста, списки и цитаты. Цвет они наследуют от родителя (`currentColor`), а размер задан в `em`, поэтому текст масштабируется вместе с размером шрифта контейнера.

Все компоненты экспортируются из `@via-profit/ui-kit/Typography`:

```tsx
import { H1, H2, Paragraph, Strong, Ul, Li } from '@via-profit/ui-kit/Typography';
```

Каждый компонент доступен и по отдельному пути, например `@via-profit/ui-kit/Typography/H1`. Экспорт по умолчанию из `@via-profit/ui-kit/Typography` — `Paragraph`.

Компоненты принимают атрибуты своего элемента, а `ref` указывает на этот элемент.

## Заголовки

`H1`–`H6` — заголовки шести уровней. Выбирайте уровень по структуре страницы, а не по размеру: программы чтения с экрана строят по заголовкам оглавление. Размер можно изменить через `styled` или `style`.

```tsx
<H1>Заголовок страницы</H1>
<H2>Раздел</H2>
<H3>Подраздел</H3>
```

## Текст

- `Paragraph` — абзац с нижним отступом. Со свойством `noMargin` отступа нет;
- `Strong` — важный текст (`<strong>`), выделяется жирным;
- `Em` — смысловое ударение (`<em>`), выделяется курсивом;
- `Del` — удалённый текст (`<del>`), например старая цена;
- `U` — подчёркнутый текст (`<u>`);
- `Span` — строчный элемент без оформления.

```tsx
<Paragraph>
  Заказ оформлен. <Strong>Курьер привезёт его завтра</Strong> с 10:00 до 14:00 —{' '}
  <Em>за час до приезда</Em> он позвонит.
</Paragraph>
<Paragraph>
  Стоимость доставки: <Del>300 ₽</Del> <U>бесплатно</U>.
</Paragraph>
```

## Списки и цитаты

- `Ul` — маркированный список, `Ol` — нумерованный, `Li` — пункт списка. Маркеры окрашены в цвет акцента;
- `Blockquote` — цитата с линией слева. У первого и последнего абзаца внутри нет внешних отступов.

```tsx
<Ul>
  <Li>Бесплатная доставка от 3 000 ₽</Li>
  <Li>Возврат в течение 14 дней</Li>
</Ul>

<Ol>
  <Li>Добавьте товары в корзину</Li>
  <Li>Укажите адрес доставки</Li>
</Ol>

<Blockquote>
  <Paragraph>Заказ пришёл на следующий день, всё аккуратно упаковано.</Paragraph>
  <Paragraph>— Анна, Москва</Paragraph>
</Blockquote>
```

## Заголовок раздела

`SectionTitle` — заголовок `H2` по центру с линией цвета акцента под текстом. `SectionDescription` — абзац по центру под ним. Они подходят для лендингов и крупных разделов страницы.

```tsx
<SectionTitle>Почему выбирают нас</SectionTitle>
<SectionDescription>
  Более 10 000 покупателей каждый месяц доверяют нам свои заказы.
</SectionDescription>
```

## Компоненты

| Компонент | Элемент | Оформление |
| --- | --- | --- |
| `H1` | `<h1>` | 2em, жирный |
| `H2` | `<h2>` | 1.5em |
| `H3` | `<h3>` | 1.25em |
| `H4` | `<h4>` | 1.1em |
| `H5` | `<h5>` | 1em |
| `H6` | `<h6>` | 0.9em |
| `Paragraph` | `<p>` | нижний отступ 0.8em; `noMargin` убирает его |
| `Span` | `<span>` | — |
| `Strong` | `<strong>` | жирный |
| `Em` | `<em>` | курсив |
| `Del` | `<del>` | зачёркнутый |
| `U` | `<u>` | подчёркнутый |
| `Ul`, `Ol`, `Li` | `<ul>`, `<ol>`, `<li>` | маркеры цвета акцента |
| `Blockquote` | `<blockquote>` | курсив, линия слева |
| `SectionTitle` | `<h2>` | по центру, линия под текстом |
| `SectionDescription` | `<p>` | по центру |

`Base` устарел — используйте `Span`.

### `Paragraph`

#### `noMargin`
Если `true`, у абзаца нет нижнего отступа.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет
