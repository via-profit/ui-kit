## Описание

Подсказка по нажатию — кнопка «?», которая по нажатию открывает всплывающий блок с пояснением. В блок помещается абзац, несколько абзацев или список, в нём можно выделять текст и переходить по ссылкам.

Ставьте её для пояснений, которые нужны не всем и не всегда: что делает кнопка, откуда берётся число, чем отличаются варианты. То, что должен увидеть каждый, пишите в [информере](../info-note/README.md).

Подсказка закрывается повторным нажатием на «?», кликом вне неё и клавишей Escape.

_Пример использования:_

```tsx
import React from 'react';
import Button from '@via-profit/ui-kit/Button';
import HintPopover from '@via-profit/ui-kit/HintPopover';

const Example: React.FC = () => (
  <span>
    <Button>Обновить список</Button>
    <HintPopover label="Что делает «Обновить список»">
      <p>Собирает список заново: все выполненные заявки клиента за выбранный период.</p>
      <p>Несохранённые правки сумм в списке при этом сбросятся.</p>
    </HintPopover>
  </span>
);

export default Example;
```

<ExampleHintPopoverBasic />

Абзацы `<p>` внутри подсказки получают отступы между собой, лишнего отступа в конце нет.

## Где ставить

Кнопка «?» берёт цвет окружающего текста и подстраивается под его размер. Поэтому её можно ставить:

- рядом с кнопкой или полем;
- в подписи поля или в заголовке блока;
- в цветной шапке диалога — кнопка будет того же цвета, что и заголовок.

```tsx
<TextField
  label={
    <>
      Срок вывоза
      <HintPopover label="Что такое срок вывоза">
        Сколько дней после заявки у компании есть на вывоз по договору.
      </HintPopover>
    </>
  }
/>
```

<ExampleHintPopoverPlaces />

Подсказка показывается поверх модальных окон: её `z-index` на единицу больше `theme.zIndex.modal`, поэтому её можно ставить и в диалогах, и в боковых панелях.

## Расположение

По умолчанию подсказка открывается под кнопкой, по левому краю (`placement="bottom-start"`). Если места не хватает, она переходит на противоположную сторону. Возможные значения — те же, что у [Popper](../popper/README.md): `top`, `bottom-end`, `right` и другие.

```tsx
<HintPopover placement="right" label="Подсказка справа">
  Открывается справа от кнопки.
</HintPopover>
```

## Подсказка по нажатию или подсказка при наведении

| | Подсказка по нажатию | [Подсказка при наведении](../tooltip/README.md) |
|---|---|---|
| Открывается | нажатием на «?» | наведением и фокусом на элементе |
| Содержимое | абзацы, списки, ссылки | одна строка |
| На сенсорных экранах | работает | не показывается |
| Для чего | пояснить, как что-то работает | подписать кнопку-иконку |

## Клавиатура и доступность

- «?» — обычная кнопка: открывается Enter и пробелом;
- Escape закрывает подсказку и возвращает фокус на кнопку;
- у кнопки есть название для программ чтения с экрана — `label`, оно же всплывает при наведении. По умолчанию это `Hint`: передавайте `label` на языке вашего интерфейса и говорите, о чём подсказка («Что делает „Обновить список“»), а не просто «Подсказка»;
- кнопка сообщает, открыта ли подсказка (`aria-expanded`), и ссылается на её содержимое (`aria-controls`).

Чтобы управлять видимостью самостоятельно, передайте `isOpen` и `onOpenChange`. `onOpenChange(isOpen)` вызывается, когда подсказка хочет открыться или закрыться.

## Переопределение

`<HintPopover>` состоит из компонентов:

- `<Button>` — кнопка «?»; своя иконка из `icon` приходит в `children`
- `<Container>` — блок с содержимым подсказки

Используйте свойство `overrides`, чтобы переопределить один или несколько компонентов. Проще всего расширить стандартный компонент с помощью `styled`. Создавайте переопределения один раз — вне компонента, а не при рендере.

_Пример использования:_ широкая подсказка с цветной полосой сверху.

```tsx
import styled from '@emotion/styled';
import HintPopover from '@via-profit/ui-kit/HintPopover';
import HintPopoverContainer from '@via-profit/ui-kit/HintPopover/HintPopoverContainer';

const Container = styled(HintPopoverContainer)`
  max-width: 30em;
  border-top: 3px solid ${({ theme }) => theme.color.accentPrimary.toString()};
`;

// Created once, outside of the component
const overrides = { Container };

<HintPopover overrides={overrides} label="Как считается цена">
  Цена в регионе — базовая стоимость, умноженная на коэффициент региона, с округлением до 10 ₽.
</HintPopover>;
```

## Свойства

#### `children`
Содержимое подсказки: текст, абзацы, список.
- Тип: `React.ReactNode`
- Обязательное: **да**

#### `label`
Название кнопки для программ чтения с экрана, оно же всплывает при наведении. Говорит, о чём подсказка.
- Тип: `string`
- По умолчанию: `'Hint'`
- Обязательное: нет

#### `icon`
Своя иконка вместо «?».
- Тип: `React.ReactNode`
- По умолчанию: «?» в круге
- Обязательное: нет

#### `placement`
Желаемое расположение подсказки.
- Тип: `AnchorPos`
- По умолчанию: `'bottom-start'`
- Обязательное: нет

#### `isOpen`
Видимость контролируемой подсказки. Передавайте вместе с `onOpenChange`.
- Тип: `boolean`
- По умолчанию: `undefined`
- Обязательное: нет

#### `onOpenChange`
Вызывается, когда подсказка хочет открыться или закрыться.
- Тип: `(isOpen: boolean) => void`
- По умолчанию: `undefined`
- Обязательное: нет

#### `offset`
Расстояние от кнопки, в пикселях.
- Тип: `number`
- По умолчанию: `6`
- Обязательное: нет

#### `zIndex`
`z-index` подсказки.
- Тип: `number`
- По умолчанию: `theme.zIndex.modal + 1`
- Обязательное: нет

#### `id`
`id` блока подсказки.
- Тип: `string`
- По умолчанию: создаётся автоматически
- Обязательное: нет

#### `overrides`
Объект для переопределения составных компонентов. Подробнее в разделе [Переопределение](#переопределение).
- Тип: `HintPopoverOverrides`
- По умолчанию: `undefined`
- Обязательное: нет
