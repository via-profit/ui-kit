## Описание

Пустое состояние показывается вместо содержимого, которого нет: пустой список, ничего не найдено по фильтру, ещё ничего не выбрано. Оно говорит, что пусто, почему и что делать дальше, — вместо голого белого места, на котором непонятно, загрузилось что-то или нет.

По умолчанию показывается иллюстрация — открытая пустая коробка. Текста по умолчанию нет: передайте его на языке вашего интерфейса.

_Пример использования:_

```tsx
import React from 'react';
import EmptyState from '@via-profit/ui-kit/EmptyState';

const Example: React.FC = () => <EmptyState>Пусто</EmptyState>;

export default Example;
```

## Заголовок, пояснение и действие

- `title` — короткая строка: что пусто («Заявок нет»);
- `children` — пояснение: почему пусто и что сделать;
- `action` — следующий шаг: одна-две кнопки.

```tsx
<EmptyState
  title="Ничего не найдено"
  action={<Button onClick={resetFilters}>Сбросить фильтры</Button>}
>
  По выбранным фильтрам заявок нет. Измените период или сбросьте фильтры.
</EmptyState>
```

<ExampleEmptyStateAction />

С `fullHeight` пустое состояние занимает всю высоту родителя и стоит посередине — например, в пустой панели или в окне, где не выбран элемент.

## Своя иллюстрация

`icon` заменяет коробку: подойдёт любая иконка или картинка. Иллюстрация берёт цвет текста `currentColor` и размер `6em`. `icon={false}` убирает иллюстрацию — для маленьких блоков, где она займёт слишком много места.

```tsx
<EmptyState icon={<SearchIcon />} title="Ничего не найдено" />
<EmptyState icon={false}>Комментариев пока нет.</EmptyState>
```

## Как писать текст

- Говорите конкретно, что пусто: «Заявок на сегодня нет», а не «Нет данных».
- Если пусто из-за фильтра или поиска — скажите об этом и предложите сбросить: иначе кажется, что данных нет совсем.
- Если пустоту можно заполнить — дайте кнопку на это действие: «Добавить клиента».

## Переопределение

`<EmptyState>` состоит из компонентов:

- `<Container>` — столбец посередине; получает `fullHeight`
- `<Icon>` — иллюстрация; своя из `icon` приходит в `children`
- `<Title>` — заголовок; выводится только с `title`
- `<Content>` — пояснение; выводится только с `children`
- `<Action>` — кнопки; выводится только с `action`

Используйте свойство `overrides`, чтобы переопределить один или несколько компонентов. Проще всего расширить стандартный компонент с помощью `styled`. Создавайте переопределения один раз — вне компонента, а не при рендере.

_Пример использования:_ иллюстрация поменьше и цвета акцента.

```tsx
import styled from '@emotion/styled';
import EmptyState from '@via-profit/ui-kit/EmptyState';
import EmptyStateIcon from '@via-profit/ui-kit/EmptyState/EmptyStateIcon';

const Icon = styled(EmptyStateIcon)`
  font-size: 3.5em;
  color: ${({ theme }) => theme.color.accentPrimary.toString()};
`;

// Created once, outside of the component
const overrides = { Icon };

<EmptyState overrides={overrides} title="Корзина пуста" />;
```

## Свойства

Помимо перечисленных ниже, `<EmptyState>` принимает атрибуты элемента `<div>`. `ref` указывает на этот же элемент.

#### `title`
Короткая строка: что пусто.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `children`
Пояснение: почему пусто и что делать.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `action`
Следующий шаг: кнопки.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `icon`
Своя иллюстрация вместо коробки. `false` — без иллюстрации.
- Тип: `React.ReactNode`
- По умолчанию: пустая коробка
- Обязательное: нет

#### `fullHeight`
Если `true`, занимает всю высоту родителя и стоит посередине.
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

#### `overrides`
Объект для переопределения составных компонентов. Подробнее в разделе [Переопределение](#переопределение).
- Тип: `EmptyStateOverrides`
- По умолчанию: `undefined`
- Обязательное: нет
