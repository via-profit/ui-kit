## Описание

Шаги показывают путь процесса: что сделано, на каком шаге он сейчас и что впереди. Например, путь заявки: создана → водитель назначен → водитель принял → выполнена → оплачена.

- `<Stepper>` — ряд шагов, `activeStep` — номер текущего шага с нуля: шаги до него выполнены;
- `<Step>` — шаг с подписью. Выполненные — бледная подложка цвета и галочка цвета, линия после них — цветом; текущий — подложка контрастного цвета темы (`accentPrimaryContrast`), обводка и номер цветом; будущие и линии к ним — бледно-серые.

_Пример использования:_

```tsx
import React from 'react';
import Stepper, { Step } from '@via-profit/ui-kit/Stepper';

const Example: React.FC = () => (
  <Stepper activeStep={2}>
    <Step>Создана</Step>
    <Step>Назначен</Step>
    <Step>Принял</Step>
    <Step>Выполнена</Step>
    <Step>Оплачена</Step>
  </Stepper>
);

export default Example;
```

## Подписи под шагами

`alternativeLabel` ставит подписи под кружками, шаги делят ширину поровну — так шаги помещаются в узкую карточку. `caption` у шага — мелкий текст под подписью: время, «1 из 2», «необязательно». `completed` отмечает шаг выполненным независимо от `activeStep` — например, оплата пришла раньше работ.

```tsx
<Stepper activeStep={2} alternativeLabel>
  <Step caption="19.10 14:20">Создана</Step>
  <Step caption="09:12">Назначен</Step>
  <Step>Принял</Step>
  <Step>Выполнена</Step>
  <Step completed caption="заранее">Оплачена</Step>
</Stepper>
```

## Вертикальные шаги и внимание

`orientation="vertical"` — шаги столбцом, например в боковой панели. `status` у шага — внимание на невыполненном шаге: `warning` — что-то не доделано, `error` — что-то пошло не так.

```tsx
<Stepper activeStep={1} orientation="vertical">
  <Step>Создана</Step>
  <Step caption="1 из 2" status="warning">
    Водитель назначен
  </Step>
  <Step caption="0 из 2">Водитель принял</Step>
</Stepper>
```

## Свойства

### Stepper

Помимо перечисленных ниже, принимает атрибуты элемента `<div>`, `ref` указывает на этот же элемент. Ряд получает роль `list`, шаги — `listitem`, текущий шаг — `aria-current="step"`.

#### `activeStep`
Номер текущего шага с нуля. `-1` — ничего не начато, число шагов — всё выполнено.
- Тип: `number`
- По умолчанию: `0`
- Обязательное: нет

#### `orientation`
Шаги в строку или в столбец.
- Тип: `'horizontal' | 'vertical'`
- По умолчанию: `'horizontal'`
- Обязательное: нет

#### `alternativeLabel`
Подписи под кружками, шаги делят ширину поровну (только в строку).
- Тип: `boolean`
- По умолчанию: `false`
- Обязательное: нет

#### `color`
Цвет выполненных и текущего шагов.
- Тип: `'primary' | 'secondary' | string`
- По умолчанию: `'primary'`
- Обязательное: нет

### Step

Принимает атрибуты элемента `<div>`, `ref` указывает на этот же элемент.

#### `children`
Подпись шага.
- Тип: `React.ReactNode`
- Обязательное: **да**

#### `caption`
Мелкий текст под подписью.
- Тип: `React.ReactNode`
- По умолчанию: `undefined`
- Обязательное: нет

#### `completed`
Шаг выполнен независимо от `activeStep`.
- Тип: `boolean`
- По умолчанию: `undefined`
- Обязательное: нет

#### `status`
Внимание на невыполненном шаге: цвет темы `warning` или `error`.
- Тип: `'warning' | 'error'`
- По умолчанию: `undefined`
- Обязательное: нет

#### `icon`
Своя иконка вместо номера.
- Тип: `React.ReactNode`
- По умолчанию: номер шага
- Обязательное: нет
