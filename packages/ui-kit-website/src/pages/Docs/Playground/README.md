# Песочница отступов

Здесь собраны компоненты, сгруппированные по классам [внутренних отступов](../theming/README.md) темы: контролы, строки списков и панели. Двигайте ползунки на панели — превью сразу перерисуется с новой темой. Остальной сайт при этом не меняется.

Размер шрифта и отступы — две разные оси. Шрифт меняет масштаб: компоненты растут целиком, потому что их размеры заданы в `em`. Отступы меняют плотность: сколько воздуха внутри элементов при том же тексте. Код темы с выбранными значениями — внизу панели.
