На страницах компонентов каждый компонент показан отдельно. Здесь собраны экраны, на которых компоненты работают вместе: так видно, как они сочетаются по размерам, отступам и цветам и как связываются состоянием.

Раскладка во всех примерах собрана из [стека](../stack/README.md) и [сетки](../grid/README.md): свои стили остались только для оформления, а не для расстановки элементов.

Все примеры живые. Под каждым есть кнопка «Показать код» с полным исходным кодом примера: его можно скопировать как основу для своего экрана. Тексты в примерах обёрнуты в `react-intl`, потому что сайт документации переведён на несколько языков; в своём приложении можно писать строки напрямую.

## Оформление заказа

Форма с проверкой полей при отправке. Поля адреса и даты доставки появляются только для доставки курьером, итог в карточке справа пересчитывается вместе со способом получения. Во время отправки кнопка недоступна и показывает спиннер.

Компоненты: [Стек](../stack/README.md), [Сетка](../grid/README.md), [Поверхность](../surface/README.md), [Текстовое поле](../text-field/README.md), [Поле телефона](../phone-field/README.md), [Селектбокс](../selectbox/README.md), [Радиокнопка](../radio/README.md), [Дейтпикер](../date-picker/README.md), [Многострочное поле](../text-area/README.md), [Чекбокс](../checkbox/README.md), [Кнопка](../button/README.md), [Индикатор загрузки](../loading-indicator/README.md), [Таблица](../table/README.md).

## Настройки профиля

Карточка профиля с аватаром, интересами-бейджами, переключателями уведомлений и выбором темы. Кнопки «Сохранить» и «Отменить» доступны, только когда есть изменения. Удаление аккаунта спрятано в аккордеон и требует подтверждения.

Компоненты: [Стек](../stack/README.md), [Сетка](../grid/README.md), [Поверхность](../surface/README.md), [Аватар](../avatar/README.md), [Текстовое поле](../text-field/README.md), [Бейдж](../badge/README.md), [Переключатель](../switch/README.md), [Группа кнопок](../button-group/README.md), [Аккордеон](../accordion/README.md), [Модальные окна](../modal/README.md), [Типографика](../typography/README.md).

## Список заказов

Таблица с поиском и фильтрами по статусу. Найденный текст подсвечивается, при смене фильтров таблицу закрывает слой загрузки. У каждой строки есть меню действий: заказ открывается в боковой панели, отмена требует подтверждения.

Компоненты: [Стек](../stack/README.md), [Поверхность](../surface/README.md), [Таблица](../table/README.md), [Текстовое поле](../text-field/README.md), [Бейдж](../badge/README.md), [Аватар](../avatar/README.md), [Подсветка подстроки](../highlighted/README.md), [Меню](../menu/README.md), [Модальные окна](../modal/README.md), [Индикатор загрузки](../loading-indicator/README.md).

## Бронирование

Выбор дат поездки в календаре, номера в карусели и количества гостей. Стоимость пересчитывается сразу, а кнопка бронирования становится доступной, когда выбраны даты и номер.

Компоненты: [Стек](../stack/README.md), [Сетка](../grid/README.md), [Календарь](../calendar/README.md), [Свайпер](../swiper/README.md), [Группа кнопок](../button-group/README.md), [Поверхность](../surface/README.md), [Бейдж](../badge/README.md), [Модальные окна](../modal/README.md).
