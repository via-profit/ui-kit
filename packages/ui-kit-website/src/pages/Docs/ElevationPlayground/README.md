# Песочница теней

Здесь собраны компоненты, у которых есть тени. Тени темы задаёт `theme.elevation`: `popup` — у всплывающих элементов и окон, `surface` — у карточек и панелей, `control` — у приподнятых частей контролов. Если значения нет, у всех компонентов уровня одна и та же тень по умолчанию.

Включите тестовые тени — яркие и заметные — и подсветку: элементы, тень которых не совпадает с тенями темы, обводятся пунктиром и попадают в список на панели. Откройте меню, подсказку и окна, чтобы проверить и их.
