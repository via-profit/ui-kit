# Песочница теней

Здесь собраны компоненты, у которых есть тени. Тени темы задаёт `theme.elevation`: `popup` — у всплывающих элементов, `surface` — у карточек и панелей. Если значения нет, компонент рисует свою тень.

Включите тестовые тени — яркие и заметные — и подсветку: элементы, тень которых не совпадает с тенями темы, обводятся пунктиром и попадают в список на панели. Откройте меню, подсказку и окна, чтобы проверить и их.
